# Novely releases

Novely is a free, native Mac writing studio for novels and picture books.

Signed and notarized installers and release notes are published in the **[Releases](https://github.com/Novly-Story/releases/releases)** tab. When a build is available, the stable download URL is:

`https://github.com/Novly-Story/releases/releases/latest/download/Novely.dmg`

**Requirements:** a Mac with Apple silicon running macOS 26 or later.

Novely has no subscription, credits, or app usage fees. If you connect a cloud AI or media provider, that provider bills your account directly.

This repository is only a public distribution channel. The application source is maintained privately by Novly Story. The first signed installer will appear here when the release is ready.
